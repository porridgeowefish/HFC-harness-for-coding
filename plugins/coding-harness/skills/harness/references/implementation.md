# 实现阶段

开始任何任务前，读取正式需求、设计结论、完整 `development-contract.md`、已批准任务包、任务匹配的 Rules，以及任务列出的代码或知识位置。

每个开发任务都接收同一份共同开发契约，只修改声明范围，并遵守其提供或消费的契约 ID。任务存在依赖时按任务包顺序执行；互不依赖且写入范围不重叠时才可并行。

先用失败测试表达验收，再写最小实现，并在 `development-summary.md` 记录测试与门禁证据。必需检查失败或能力未配置不等于通过。若实现必须改变契约，停止并回到设计；更新共同契约并重新获得任务包批准。当前快照的开发验收未记录前不得提交 MR 评审。
