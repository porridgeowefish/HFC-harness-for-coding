# 设计阶段

读取已发布需求、相关长期知识、源码入口和本操作必须装配的 Rules。将不确定性与备选方案保留在 `design-alignment.md`；只有已确认的范围、边界、覆盖关系和取舍进入 `design-decision.md`。

设计结论确认后写 `development-contract.md`。它是所有开发任务共同读取的唯一契约正文，只按需装配 `templates/contracts/` 中适用的 HTTP API、公共接口、数据、跨任务集成和共享行为块。普通状态、权限和行为结果保留在验收标准中；只有多个任务必须共享同一语义时才提升为共同契约。

共同契约完整后才生成 `task-package.md`。每个任务必须声明负责和消费的契约 ID、修改范围、验证方式及依赖顺序。任务包经明确批准后停止；开发等待下一次调用。
