# Solution design

Read the published requirement, relevant `docs/knowledge/`, source and mandatory Rules selected for the operation. Keep uncertainty and alternatives in `design-alignment.md`; only confirmed scope, boundaries, shared contracts and coverage enter `design-decision.md`. Stop before development until the task package is approved.

与用户交流遵循 harness-orchestrator 的用户输出协议：一句话说明流程位置，最多 3 行下一步选项（标注推荐），决策时只呈现决策点与选项，不展开内部实现。
